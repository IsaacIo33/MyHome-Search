About MyHome

MyHome started as a simple Meta Search Engine Project that IO Studio (IsaacIo33) was working on and right now it kind of still is but the MyHome Project was grown into one of IO Studio's Main Projects in just 1 day.

MyHome gets it's Results Live from Yahoo! Search.

You can contact MyHome here.

MyHome is now Open Source and you can view it's source code here.

Privacy

MyHome doesn't Track you but Yahoo! may have some of your Search Query Data when MyHome fetches Search content from Yahoo!.

For more Information about your Privacy on MyHome you can contact MyHome here.

MyHome doesn't Sell your Data.

Extra Details

The main Search Fetching part of MyHome was written in PHP and JavaScript.

The UI of MyHome was written in HTML, CSS and JavaScript.

MyHome works on most modern Browsers and REQUIRES JAVASCRIPT to NOT be Disabled.

Features

MyHome offers Very Fast Internet Search which works good on Fast Internet and works better on 4GB and above (of RAM).

"But what if I have JavaScript disabled?"

First off why do you have JavaScript Disabled the most popular websites need JavaScript. If JavaScript is Disabled almost all websites break because JavaScript is used to make a Website function so if it's Disabled you not letting Websites function so Websites will break with JavaScript disabled.
